## <a id="cu02"></a>CU02 — Enviar postulación a la Beca Comedor

El Postulante completa un asistente de tres pasos (perfil, formulario socioeconómico, documentos y envío); el sistema valida, registra la postulación en «pendiente», entrega un comprobante y pide el puntaje a la IA en segundo plano. Una «devuelta» se corrige y se reenvía por el mismo camino.

## <a id="cu03"></a>CU03 — Precalificar con IA
